# جامیار

وب‌اپ فارسی و راست‌چین برای مدیریت مجموعه فروشگاهی: موجودی، پرسنل شعب، و حسابداری عملیاتی.

## اجرا روی سیستم اصلی

```bash
docker compose up -d
npm install
npx prisma migrate deploy
npx prisma db seed
npm run dev
```

ورود پیش‌فرض: `owner@jamyar.local` / `admin1234`

حساب‌های نمونه دیگر در `prisma/seed.ts` هستند (مدیر شعبه، انباردار، حسابدار، کارمند).

## پیش‌نیاز

- Node.js 20+
- Docker برای PostgreSQL (یا یک دیتابیس سازگار)
- کپی `.env.example` به `.env` و تنظیم `AUTH_SECRET`

## محدوده

موجودی کالا و انبار، پرسنل و نقش‌ها، فاکتور خرید/فروش، اسناد حسابداری و گزارش ساده. صندوق فروش و سخت‌افزار بارکد در این نسخه نیست.
